# GitHub Repository Details

## Repository Name

FileTreeReporter

## Short Description

A lightweight PowerShell tool that prints colorful folder trees and exports plain-text and dark HTML reports.

## Longer Description

FileTreeReporter (Ftree) is a Windows PowerShell utility for generating readable folder and file tree reports. It supports interactive prompt mode, direct path mode, full paths beside tree items, plain-text reports, dark-theme HTML reports, symlink-safe traversal, execution logs, and PATH-friendly launchers.
